# hoopster-track
This is a project where the application tracks the live scores and statistics of your favorite basketball player in the NBA.
The players of whom you can view the data currently are : Stephen Curry, LeBron James, LaMelo and Luka Dončić. 

To build the application I will use Python as a primary language by applying the knowledge I have gained through Dr Charles Servance's PY4E Course. If it is a web interface, I will use my previous knowlegde of HTML and CSS.
